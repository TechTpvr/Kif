# کیف‌نت v2

نسخه بازطراحی‌شده برای مدیریت دخل و خرج شخصی.

- طراحی موبایل‌محور و PWA برای Android و iOS
- تم روشن/تیره و ۸ رنگ پویا
- موجودی با رنگ انتخابی هماهنگ می‌شود
- ثبت دخل، خرج، حساب، کارت، بودجه، چک، قسط و یادداشت
- گزارش ماهانه، دسته‌بندی هزینه و خروجی CSV/چاپ PDF
- بازار طلا و سکه از اتحادیه طلا و جواهر تهران و ارز از منبع بازار ارز
- داده‌های تراکنش در مرورگر دستگاه ذخیره می‌شود

## GitHub Pages

همه فایل‌ها را در ریشه branch اصلی قرار بده و Pages را روی `main / root` بگذار.

## نرخ بازار

اتصال مستقیم مرورگر به بعضی منابع ممکن است به CORS وابسته باشد؛ کد نرخ‌ها را با تلاش برای دریافت مستقیم و نگه‌داری آخرین نرخ دریافت‌شده پیاده‌سازی کرده است. برای نرخ کاملاً پایدار در نسخه نهایی بهتر است یک API/Proxy اختصاصی سمت سرور اضافه شود.

## پیامک

تحلیل دستی متن پیامک در نسخه وب وجود دارد. خواندن خودکار SMS نیازمند نسخه Android با مجوز SMS است؛ iOS اجازه مشابهی به وب‌اپ نمی‌دهد.
