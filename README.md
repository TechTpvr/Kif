# کیف‌نت V3

نسخه V3 کیف‌نت برای مدیریت دخل و خرج شخصی، با طراحی موبایل‌محور و PWA.

## تغییرات V3
- صفحه شروع ۳.۶ ثانیه‌ای با لوگوی اصلی `logo.png` و انیمیشن ورود از چپ به راست.
- شعار «هوشمندانه مدیریت کن ♥» در پایین صفحه شروع؛ رنگ قلب با رنگ برند هماهنگ است.
- هیچ کدی برای لوگوی اصلی از `logo.svg` استفاده نمی‌کند؛ لوگوی مرجع پروژه فقط `logo.png` است.
- عنوان هدر: «کیف‌نت / مدیریت دخل و خرج».
- کارت موجودی با گرادیان پایدار و هماهنگ با رنگ انتخابی؛ بدون وابستگی به `color-mix` در پس‌زمینه اصلی.
- حالت روشن/تیره و رنگ‌های پویا.
- ثبت دخل، خرج، حساب، کارت، بودجه، چک، قسط و یادداشت.
- جست‌وجو و فیلتر تراکنش‌ها.
- گزارش ماهانه و دسته‌بندی هزینه‌ها.
- بازار طلا، سکه و ارز با نگهداری آخرین نرخ دریافت‌شده.
- تحلیل دستی پیامک بانکی در نسخه وب؛ خواندن خودکار SMS نیازمند اپ Android و مجوز مربوطه است.

## اجرا روی GitHub Pages
تمام فایل‌ها را در ریشه repository قرار بده و GitHub Pages را روی `main / root` تنظیم کن.

## نکته فنی
این نسخه همچنان یک PWA سمت‌کاربر است و داده‌های فعلی در `localStorage` دستگاه ذخیره می‌شوند. احراز هویت، دیتابیس ابری، همگام‌سازی چنددستگاهی، SMS خودکار Android و API پایدار بازار نیازمند Backend/Native layer هستند و نباید با GitHub Pages خالص شبیه‌سازی شوند.
