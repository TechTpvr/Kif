# کیف‌نت V4

نسخه V4 بازنویسی و اصلاح‌شده برای GitHub Pages.

## چهار لوگوی جداگانه
- `logo.png` — لوگوی اصلی هدر در حالت روشن
- `logo-bbx.png` — لوگوی هدر در حالت تیره
- `logo-open.jpg` — لوگوی شروع برنامه در حالت روشن
- `logo-dark.jpg` — لوگوی شروع برنامه در حالت تیره

این فایل‌ها دقیقاً از چهار تصویر تعیین‌شده استفاده می‌کنند و نقش آن‌ها با هم جابه‌جا نمی‌شود.

## شروع برنامه
Splash حدود ۳.۶ ثانیه نمایش داده می‌شود؛ لوگوی شروع از سمت چپ با حالت محو وارد می‌شود و شعار «هوشمندانه مدیریت کن» در پایین قرار دارد.

## اصلاحات V4
- کش سرویس‌ورکر به `kifnet-v4-cache` ارتقا داده شد.
- داده‌های نسخه V3 در اولین اجرای V4 قابل مهاجرت هستند.
- سازگاری بیشتر با مرورگرهای قدیمی با حذف وابستگی‌های ضروری به `color-mix()`.
- موجودی نمایش‌داده‌شده هر حساب/کارت با تراکنش‌های همان حساب محاسبه می‌شود.
- مودال‌ها دکمه بازگشت/بستن دارند.
- تم روشن/تیره/سیستم و رنگ برنامه حفظ شده است.
- داشبورد، تراکنش، حساب و کارت، بودجه، گزارش، بازار، چک/قسط/وام، یادداشت، جستجو و پشتیبان فعال هستند.

## انتشار
همه فایل‌های این ZIP را در ریشه Repository قرار بده و فایل‌های نسخه قبلی را جایگزین کن.
