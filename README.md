# کیف‌نت — KifNet

نسخه‌ی وب/PWA مینیمال مدیریت دخل و خرج، آماده برای GitHub Pages.

## اجرا روی GitHub
1. کل محتویات این پوشه را در ریشه‌ی یک Repository قرار بده.
2. در GitHub برو به **Settings → Pages**.
3. Source را روی **Deploy from a branch** بگذار و Branch اصلی و پوشه `/ (root)` را انتخاب کن.
4. بعد از Deploy، سایت با آدرس GitHub Pages باز می‌شود.

## امکانات این نسخه
- رابط RTL فارسی و موبایل‌محور
- تاریخ هجری شمسی و ساعت ایران
- ثبت دخل/خرج، دسته‌بندی، حساب و یادداشت
- داشبورد موجودی، دخل و خرج ماه
- بودجه‌ی ماهانه و بودجه‌ی دسته‌بندی
- گزارش ۶ ماه اخیر و مقایسه ماه‌ها
- تحلیل دسته‌بندی هزینه‌ها و روند دخل/خرج
- خروجی Excel-compatible به صورت CSV با UTF-8
- چاپ گزارش برای ذخیره به PDF از مرورگر
- حساب‌ها، یادداشت‌ها، چک/قسط/وام
- تحلیل دستی متن پیامک بانکی
- تم روشن/تیره و ۸ رنگ
- PWA و کش آفلاین

## نکته‌ی مهم درباره‌ی دو قابلیت
### پیامک خودکار
مرورگر و GitHub Pages به SMS گوشی دسترسی مستقیم ندارند. برای «مثل پولکی» و خواندن خودکار SMS باید نسخه Android با مجوزهای مربوط به SMS یا یک سرویس واسط امن ساخته شود.

### قیمت لحظه‌ای طلا/دلار/سکه
برای قیمت زنده باید یک API معتبر و قابل اتکا به برنامه وصل شود. کلید API نباید داخل JavaScript عمومی یا Repository عمومی GitHub قرار بگیرد. راه درست، قرار دادن API در Backend/Serverless Function و فراخوانی آن از سایت است.

## امنیت
این نسخه داده‌های مالی را در localStorage همان مرورگر نگه می‌دارد و هیچ کلید خصوصی داخل کد ندارد. این به معنی امنیت بانکی یا رمزنگاری کامل نیست. برای محصول واقعی باید احراز هویت، TLS، رمزنگاری سمت سرور، کنترل دسترسی، rate limiting، audit log، پشتیبان‌گیری امن و مدیریت secret در Backend اضافه شود.

## توسعه‌ی بعدی
ساختار این نسخه عمداً بدون فریم‌ورک و بدون Build Step است تا کاربر غیر برنامه‌نویس بتواند مستقیماً آن را روی GitHub Pages قرار دهد. برای نسخه تولیدی، Backend امن را می‌توان جداگانه به همین UI متصل کرد.
